## 四、架构决策（冻结，各写 ADR）

- **D1 存储**：单 PostgreSQL 16 + pgvector 承担业务/向量/关键词/轨迹四职责。前提=规模假设（单项目 ≤10 万 chunks、≤10 项目、单机）。不引入 ES/Milvus/MinIO；P0–P2 不引入 Neo4j。P3 仅当 GraphRAG 对照评测显示稳定收益时允许 Neo4j 作为 sidecar，PostgreSQL 继续作为文档、chunk、run、权限与引用的真相源。
- **D2 语料与解析优先级**：语料 = mini-mall-order（已核查，见〇-2）。解析顺序 Markdown(P0) → Java+配置文件(P1) → OpenAPI/PDF/Python(P2)。P0 摄取范围：`docs/**/*.md` + 根级 `README*.md`（CLAUDE.md/AGENTS.md/TASKMASTER.md 暂不摄取——含指令样式文本，留作 P2 prompt injection 测试样本）。
- **D3 Embedding**：候选经基准测试后冻结（ADR-002）。**冻结前禁止编写含 vector 维度的迁移**。
- **D4 LLM**：DeepSeek（已确认），经薄 `LLMClient` Protocol + OpenAI 兼容适配器接入；每个适配器配 Fake 实现供测试。模型版本、实测延迟与单价在 T1 smoke 后记入 ADR-004。
- **D5 编排**：P1 用 LangGraph（不启用 checkpointer，run 原子执行，失败即 failed）。P0 无编排框架。
- **D6 LLM/确定性边界**：在线路径恰有 4 个 LLM 调用点——plan（意图+子查询，1 次）、evaluate（每轮 1 次）、refine（≤1 次）、generate（含重生成 ≤2 次）；单 run 硬上限 6 次。**所有控制流分支由确定性代码依据 LLM 的结构化输出信号判定**；每个调用点有解析失败默认值与降级路径；解析失败重问 1 次属传输重试，计入预算。冲突判定、NLI、评测 judge 不在在线路径。
- **D7 项目隔离**：① Repository 以 project_id 实例化，方法不接受外部 project_id；② documents/chunks.project_id NOT NULL + FK；③ 双项目隔离集成测试（CI 必跑）；④ CI 静态扫描：sqlalchemy 查询构造仅允许出现在 repositories 模块；⑤ RLS 为 P2 可选纵深防御。
- **D8 注入风险（修正版）**：只读工具面消除执行类风险；剩余风险=同项目内敏感内容被诱导写入答案（缓解：摄取期 secret 扫描脱敏，承认不完备）、恶意文档被引用为证据（引用保证可溯源不保证为真）、答案/轨迹传播恶意链接与命令文本（输出层确定性标记/剥离）、日志轨迹二次暴露（脱敏 processor）。统一措辞："分层降低，不可消除"。
- **D9 引用校验**：在线=确定性 L0（E# 可解析到真实 chunk，P0 起）+ L1（引文与原文模糊匹配≥阈值，P1 起）；重生成仅由 L0/L1 违规触发。L2 语义支持度=离线评测（P2）。
- **D10 工程基线**：uv/Ruff/Pyright/pytest/structlog/Alembic/Compose/GitHub Actions，P0 起生效。
- **D11 P2/P3 扩展边界（ADR-009）**：① LangFuse 是非阻塞观测接缝，故障不得拖垮问答；② MCP 仅暴露复用 Repository 隔离的只读工具；③ LangChain 只随 LangGraph 有界使用 `langchain-core`，不得替换 `LLMClient`/`Embedder`/Repository；④ LlamaIndex 仅做隔离对照实验；⑤ n8n 只编排外部事件/API，不复制核心逻辑；⑥ 云部署封顶为单平台/单区域/单实例+基本监控；⑦ Multi-Agent/GraphRAG 由收益评测门控。

## 五、仍待实验验证的假设（不得当事实引用）

① embedding 候选的质量/资源/延迟（基准解决）；② embedding+reranker 8GB VRAM 共存（P2 引入前实测）；③ PG FTS+预分词对 Java 标识符与中文的实际召回（P1 评测验证）；④ DeepSeek 结构化输出稳定率与 P50 延迟（T1 smoke）；⑤ mini-mall 语料摄取后的实际 chunk 数；⑥ RRF 相对纯向量的增益（P1 评测对比，无增益需如实记录）；⑦ LangFuse 集成的脱敏、可靠性与实际诊断收益；⑧ MCP 客户端兼容性与工具粒度；⑨ Multi-Agent 相对单 Agent 的质量收益能否覆盖额外成本；⑩ GraphRAG 相对 Hybrid 的收益及索引成本。
