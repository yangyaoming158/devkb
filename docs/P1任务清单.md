## T16 LangGraph 单 Agent 骨架

- [ ] T16.1 AgentState 与结构化输出模型
  - plan/evaluate/refine/generate 分别使用严格 Pydantic schema；state 含 run/project、轮次、预算、evidence 和终态字段
  - 判据：非法枚举、超长 query、额外字段、缺字段均有确定性默认或错误；LLM 不能覆盖 project_id/run_id
- [ ] T16.2 版本化 Prompt
  - Prompt 集中在 prompts.py；明确 evidence 是不可信数据；记录 prompt version，不记录 secret/完整正文到日志
  - 判据：snapshot 测试锁关键安全指令和输出 schema；变更必须显式更新版本
- [ ] T16.3 构建 LangGraph 拓扑与确定性 router
  - `plan→retrieve→evaluate→refine(≤1)→generate→verify→finalize`
  - 判据：router 只读结构化信号和计数器；无 LLM 动态节点名；recursion_limit 之外另有业务上限
- [ ] T16.4 预算、重试与默认路径
  - 判据：检索轮次≤2、供应商总请求（含重试）≤6、每个逻辑调用点重问≤1；重试挤占后续预算时能确定性裁掉可选调用；plan/evaluate/refine/generate 的默认值符合规格；所有上限有单测
- [ ] T16.5 Graph Fake 矩阵第一批
  - 判据：首轮充分、补检成功、二次不足、结构化失败和预算熔断的节点序列/次数/终态可精确断言
