## 任务目标

## 背景与当前问题

- 当前行为（本轮只读探针在 `608fb46` 上实测，未改任何业务代码）：

### 数据流

### 异常与恢复流

- E0 为空（无 claim 且正文无有效 `[E#]`）→ 所有条目 `cited_paths=()`，行为与 `608fb46` 逐字节一致。
- E1 不成立（存在不在 E0 内的可解析目标，如 `RagService 和 DocumentRepository …`）→ **整条**不标注，两段各自走既有 `evidence_history`/`corpus_index` 链，输出与今日一致（PG-03 闭合）。
- 条目无任何可解析目标（纯散文）→ E1 不成立 → 不标注。
- E1 成立但 E2 不成立（残余命题，如案例七）→ 只追加"未经确定性核验"的披露句 + 冲突告警，**不替换、不删除、不声称已支撑**（PG-01 的可证部分）。
- `CorpusProfile.known=False` → CC1 不依赖语料快照，判定不受影响。
- `finalize_consistency` 只判定与告警，不抛异常；检测到"输入 mode 比返回 mode 更轻"的不可能状态时返回更保守一侧并记告警。
