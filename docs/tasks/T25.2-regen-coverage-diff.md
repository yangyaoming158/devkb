## 实现计划

判据 `regen_full_block(generate_calls, first, draft_not_found, evidence_ids) -> tuple[bool, list[str]]` 是**纯函数**。参数口径冻结如下（PG-04-R）：

- `generate_calls`：`AgentState["generate_calls"]`，**P1 判 `== 2`**（不用 `first is not None` 代理）；
- `first`：`DraftSnapshot | None`；
- `draft_not_found`：**第二稿 `GenerateOutput.not_found` 原始字段**，与 `nodes.py:1018` 的 `not draft.not_found` 同源；**不是** T23 校准后的 `not_found`（U14 锁定）；
- `evidence_ids`：终态 `state["evidences"]` 的 `evidence_id` 元组。

三个前置条件——**P1** `generate_calls == 2`、**P2** `first.evidence_ids == evidence_ids`、**P3** `first.not_found` 非空且 `draft_not_found` 为空——全部成立才返回 `(True, [否决 warning])`；任一不成立返回 `(False, [...])`（可含计数/不适用类 warning，但**永不改变终态**）。

### 数据流

`generate`(第一次) 写 `first_draft{not_found, evidence_ids}` → `verify` L0/L1 失败 → `generate`(第二次) 覆写 `answer_draft`、**不动** `first_draft` → `finalize` 读 `first_draft` 与终稿 `draft.not_found`，算 `regen_full_block` → 结果**只作用于 `nodes.py:1051` 的 `full` 判定与 `warnings`**；`raw_not_found` 组装、T23 校准、T25.1 兜底全部保持原样。

### 状态流

新增字段一个，转换只有 `None → DraftSnapshot`，发生在**首次 `generate`**。不变式：`first_draft is not None ⟺ generate_calls >= 1`（U5 覆盖 0/1/2 稿三态）。**`generate_calls == 1` 且 `first_draft` 非空是合法常态**（单稿通过验证的正常 run），不是非法态。

### 异常与恢复流

- 第一次 `generate` 传输/格式失败：快照仍写入（`not_found=()`），`route_after_verify` 直接去 finalize；P1 不成立，判据空转。
- 第二次 `generate` 走冻结默认值：终稿 `not_found=[]`，P1∧P2∧P3 成立 → **否决 `full`**（I3）。
- 预算耗尽未重生成：`generate_calls == 1`，P1 不成立 → 终态与基线逐字节一致（I4）。
- 证据集在两稿间变化（当前拓扑不可达，作为结构性 fail-closed 保留）：P2 不成立 → 不否决，只留一条"两稿证据集不同，跨稿复检不适用"的可证 warning（U8）。
