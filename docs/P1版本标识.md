# P1 契约版本标识

> 冻结日期：2026-07-17 ｜ 任务：T11.4
>
> 本文是《P1 实现规格》已冻结契约的版本盘点，不是新实现规格，也不建立多版本兼容框架。机器真相源为 `src/devkb/contracts.py`。

## 冻结值

| 契约 | 报告字段 | P1 初始标识 | 何时递增 |
|---|---|---|---|
| Agent Prompt bundle | `prompt_version` | `p1-agent-v1` | plan/evaluate/refine/generate 任一 Prompt 文本、输出 schema 说明、安全指令或证据包装口径改变 |
| AgentState schema | `agent_state_schema_version` | `p1-agent-state-v1` | 状态字段、类型、枚举或字段语义改变 |
| Answer schema | `answer_schema_version` | `p1-answer-v1` | 对外 Answer 字段、类型、mode/claim/citation 语义改变 |
| HTTP API contract | `api_version` | `p1-api-v1` | HTTP 方法、路径、请求/响应 schema 或稳定错误码契约改变 |

版本标识和 `devkb.__version__` 相互独立。包的内部修复、测试补充或文档更新不自动提升上述契约版本。

## Prompt version 口径

`p1-agent-v1` 是 plan/evaluate/refine/generate 四类在线 Prompt 的整体 bundle 版本，不为每个节点新建独立版本系统。Prompt 仍须按《P1 实现规格》收口到 `agent/prompts.py`；后续 T16 实现时引用此常量，不复制字面量。

## API version 口径

P1 仍按冻结规格提供 `POST /ask`、`GET /runs/{run_id}` 和 `GET /healthz`，不增加 `/v1` URL 前缀。`p1-api-v1` 是报告和 API schema 元数据使用的契约标识，不代表多版本路由已实现。

## 报告与变更纪律

- 新评测报告必须调用 `contract_versions()` 写入上述四个字段，不在报告代码中复制版本字面量。
- 任一契约标识递增后，必须生成新的带时间戳报告；不得覆盖、重写或删除旧报告。
- 仅递增发生语义变化的那个标识。P1 不实现自动协商、多版本 adapter、弃用周期或迁移注册表。
