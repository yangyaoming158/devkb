## 1. 环境事实与待验证项

已验证（2026-07-12 实测）：WSL2 内存 9.7GB / 8 核 / swap 8GB；RTX 4060 Laptop 8GB（驱动 610.62）；磁盘充足。
待验证（基准第 0 步）：CUDA 版 PyTorch 安装与 `torch.cuda.is_available()`；pgvector compose 启动与扩展可用。

## 2. 候选 embedding 模型（许可证按《范围冻结》第六节清单核查）

| 候选 | 维度 | 定位 |
|---|---|---|
| BAAI/bge-m3 | 1024 | 多语种+长上下文，最重 |
| Qwen3-Embedding-0.6B | 1024 | 多语种，支持指令前缀 |
| intfloat/multilingual-e5-base | 768 | 中量级多语种 |
| BAAI/bge-base-zh-v1.5 | 768 | 中文强、英文/代码存疑（对照组） |

## 3. 测试语料与质量小测

- 语料：mini-mall-order 抽样 ~300–500 段（docs/ 文档 + Java 代码片段；基准脚本用朴素固定长度切分，不依赖 P0 代码）。
- 质量小测：复用《Evaluation-v0》dev 检索集的 15 问子集，指标 Recall@5（精确扫描，无索引误差）。

## 4. 实验矩阵与指标

每模型 × {GPU fp16, CPU} 测：权重磁盘大小、加载时间、加载后 RAM/VRAM 实测、批量吞吐（chunks/s，batch 8/32/64，512 token 文本）、单查询嵌入延迟 P50、Recall@5。

## 5. 决策规则（预先冻结，防事后拍脑袋）

1. Recall@5 领先 >5pt → 选质量最高者；
2. 差距 ≤5pt → 选资源占用与延迟更低者；
3. 淘汰线：GPU 加载后 VRAM >4GB（为 P2 reranker 共存留余量，该余量本身是假设、届时另测）或加载时间 >60s 或 CPU 单查询 >2s（CI/无 GPU 回退可用性）。
